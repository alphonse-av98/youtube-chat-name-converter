# YouTube Chat Name Converter

YouTubeのライブチャット欄に表示されるハンドルネーム（例: `@user-id`）を、元のチャンネル名に自動変換するChrome / Edge 向け拡張機能（Manifest V3）です。

## 機能

*   **自動変換**: 通常チャット、Super Chat、Super Sticker、メンバーシップ加入・ギフト購入通知のハンドルネームをチャンネル名に置き換えます。
*   **ツールバーポップアップ**: 拡張機能アイコンを左クリックするだけで、変換の **ON/OFF 切替**、**視聴中チャンネルの対象リスト追加/削除**、キャッシュ件数確認、詳細設定への移動ができます。
*   **ツールチップ表示**: 変換後の名前にマウスカーソルを合わせると、元のハンドルネームを確認できます。
*   **キャッシュ機能**: 一度取得したチャンネル名を `chrome.storage.local` に保存し、次回以降は高速に表示します（有効期限: 30日、最大5,000件で古いものから自動整理）。
*   **チャンネル制限**: 特定の配信者のチャット欄でのみ機能を有効にする設定が可能です（大文字・小文字および日本語ハンドルに対応。設定変更時は表示中のチャットにも即時反映されます）。

## インストール方法（かんたん手順）

Git などの開発ツールは不要です。[Releases ページ](https://github.com/alphonse-av98/youtube-chat-name-converter/releases/latest) から完成版 ZIP をダウンロードして導入できます。

1.  [**最新リリース（Releases）**](https://github.com/alphonse-av98/youtube-chat-name-converter/releases/latest) を開き、**Assets** にある `youtube-chat-name-converter-v*.zip` をダウンロードします。
2.  ダウンロードした ZIP ファイルを解凍（展開）します。
    *   **Windows**: ZIP ファイルを右クリック → **「すべて展開」** をクリックします。
    *   **Mac**: ZIP ファイルをダブルクリックして解凍します。
    *   ※ 解凍後のフォルダは削除せず、ドキュメントフォルダ等に残しておいてください。
3.  Google Chrome を開き、アドレスバーに `chrome://extensions` と入力して Enter を押します（Edge の場合は `edge://extensions`）。
4.  画面の **「デベロッパー モード」** スイッチをオンにします。
5.  **「パッケージ化されていない拡張機能を読み込む」**（Edge は「展開して読み込み」）をクリックし、手順 2 で解凍したフォルダ（中に `manifest.json` があるフォルダ）を選択します。

### アップデート方法
新しいバージョンが公開されたら、同じフォルダへ新しい ZIP を上書き解凍し、`chrome://extensions` 画面でこの拡張機能の **再読み込み（更新アイコン）** をクリックしてください。保存した設定やキャッシュはそのまま引き継がれます。

## 使い方

### 基本的な使い方
拡張機能をインストールした状態でYouTubeのライブ配信ページ（またはアーカイブ）を開くと、チャット欄のハンドルネームが自動的にチャンネル名に変換されます。

### ポップアップ（左クリック）
ツールバーの拡張機能アイコンを左クリックすると、クイック操作用のポップアップが開きます（アイコンが見当たらない場合は、ツールバー右上のパズルマークからピン留めしてください）。

*   **チャンネル名へ自動変換（ON/OFF）**: 全体の変換をワンクリックで切り替えられます（オフにすると表示中のチャットも元のハンドル表示へ即時復元されます）。
*   **視聴中のチャンネル**: YouTube ライブ配信タブで開いた場合、現在視聴中の配信者をワンクリックで対象リストへ追加・削除できます。
*   **詳細設定を開く**: オプション画面を開きます。

### 詳細設定（オプション）
ポップアップ内の「詳細設定を開く」、または拡張機能アイコン右クリック →「オプション」から開けます。

*   **自動変換のオン / オフ**: ポップアップと連動して変換の有効・無効を切り替えられます。
*   **キャッシュの管理**: 保存済みキャッシュ件数の確認および全消去ができます（YouTubeタブを開いていなくても消去可能です）。
*   **対象チャンネルの制限**:
    *   特定の配信者のチャットでのみ変換を行いたい場合、その配信者のハンドルネーム（例: `@youtube`）またはチャンネルURLをリストに追加します。
    *   リストが空の場合は、すべてのチャンネルで有効になります。

### 新バージョンのリリース手順

1. `manifest.json` と `package.json` の `version` を更新してコミット・プッシュします。
2. 対応するバージョンタグを作成してプッシュすると、GitHub Actions がテスト実行後に配布用 ZIP を自動生成して GitHub Releases へ公開します。

```bash
git push origin v1.1.0
```

## 注意事項

*   YouTubeの仕様変更により、予告なく動作しなくなる可能性があります。
*   初回表示時はチャンネル名を取得するために通信が発生するため、変換まで一瞬ラグがある場合があります。
*   ポップアップチャットなど親ウィンドウの配信者情報へアクセスできない環境では、「対象チャンネルの制限」にハンドルが登録されている場合に変換が抑制されます。
