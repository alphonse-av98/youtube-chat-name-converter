# YouTube Chat Name Converter

YouTubeのライブチャット欄に表示されるハンドルネーム（例: `@user-id`）を、元のチャンネル名に自動変換するChrome拡張機能（Manifest V3）です。ビルド不要でそのまま読み込んで利用できます。

## 機能

*   **自動変換**: 通常チャット、Super Chat、Super Sticker、メンバーシップ加入・ギフト購入通知のハンドルネームをチャンネル名に置き換えます。
*   **ツールチップ表示**: 変換後の名前にマウスカーソルを合わせると、元のハンドルネームを確認できます。
*   **キャッシュ機能**: 一度取得したチャンネル名を `chrome.storage.local` に保存し、次回以降は高速に表示します（有効期限: 30日、最大5,000件で古いものから自動整理）。
*   **チャンネル制限**: 特定の配信者のチャット欄でのみ機能を有効にする設定が可能です（大文字・小文字および日本語ハンドルに対応。設定変更時は表示中のチャットにも即時反映されます）。

## インストール方法

この拡張機能はChromeウェブストアには公開されていません。以下の手順で手動インストールしてください。

1.  このリポジトリをZIPでダウンロードして解凍するか、`git clone` します。
2.  Google Chromeを開き、アドレスバーに `chrome://extensions` と入力します。
3.  右上の **「デベロッパー モード」** スイッチをオンにします。
4.  左上の **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
5.  解凍したフォルダ（`manifest.json` が含まれているフォルダ）を選択します。

## 使い方

### 基本的な使い方
拡張機能をインストールした状態でYouTubeのライブ配信ページ（またはアーカイブ）を開くと、チャット欄のハンドルネームが自動的にチャンネル名に変換されます。

### 設定（オプション）
拡張機能のアイコンを右クリックして「オプション」を選択すると、設定画面が開きます。

*   **キャッシュの管理**: 保存済みキャッシュ件数の確認および全消去ができます（YouTubeタブを開いていなくても消去可能です）。
*   **対象チャンネルの制限**:
    *   特定の配信者のチャットでのみ変換を行いたい場合、その配信者のハンドルネーム（例: `@youtube`）またはチャンネルURLをリストに追加します。
    *   リストが空の場合は、すべてのチャンネルで有効になります。

## ディレクトリ構成

```text
.
├── manifest.json
├── options.html
├── options.css
├── package.json
├── src/
│   ├── shared/
│   │   ├── constants.js   # 定数・セレクタ・ストレージキー定義
│   │   ├── handle.js      # ハンドル解析・正規化・HTMLエンティティデコード
│   │   └── storage.js     # chrome.storage.local 操作・キャッシュ整理
│   ├── content/
│   │   ├── cache.js       # メモリ＋ストレージ2層キャッシュ・失敗クールダウン
│   │   ├── fetcher.js     # 同時実行制御キュー・重複排除・タイムアウト付き取得
│   │   ├── chat.js        # チャットDOM監視・変換・復元・許可判定
│   │   └── main.js        # コンテンツスクリプトのエントリーポイント
│   └── options/
│       └── options.js     # 設定画面ロジック
└── test/
    ├── run-tests.js       # ゼロ依存テストランナー（Node.js 16+）
    └── *.test.js          # 各モジュールのユニットテスト
```

## テストの実行

追加パッケージのインストール不要で、Node.js（v16以上）のみでユニットテストを実行できます。

```bash
npm test
```

## 注意事項

*   YouTubeの仕様変更により、予告なく動作しなくなる可能性があります。
*   初回表示時はチャンネル名を取得するために通信が発生するため、変換まで一瞬ラグがある場合があります。
*   ポップアップチャットなど親ウィンドウの配信者情報へアクセスできない環境では、「対象チャンネルの制限」にハンドルが登録されている場合に変換が抑制されます。
